# Architecture

## Overview

`karolinejangola` is the marketing/booking website for psychoanalyst Karoline Jangola. The **source** is a React 18 + Vite + TypeScript + Tailwind SPA under `app/`. `npm run build` compiles it to `app/dist/`, and `npm run publish:site` copies that build to the **repo root**, which GitHub Pages serves at `karolinejangola.com`.

> The React source was reconstructed on 2026-07-25 from the compiled live bundle after the original was lost. `docs/reference/current-site-inventory.md` is the byte-level ground-truth capture that drove the rebuild.

## Structure

| Path | Purpose |
|------|---------|
| `app/src/` | React source — `pages/`, `sections/` (homepage), `components/` (Nav, Footer, Accordion, WhatsAppLink, Seo), `lib/` (gtag conversion, whatsapp, n8n tracking), `data/` (all copy + config as typed modules) |
| `app/scripts/prerender.mjs` | Playwright post-build snapshot of every route → static SEO HTML (blog routes derived from the rendered `/blog` DOM); regenerates `sitemap.xml` |
| `app/scripts/publish.mjs` | Copies `app/dist/` → repo root (allowlist delete + denylist protecting `.git`/`docs`/`app`/root docs; asserts `CNAME`) |
| repo root: `index.html`, `assets/`, `blog/**`, `404.html`, `sitemap.xml`, `CNAME`, favicons, `og-image.jpg` | **Build output** served by GitHub Pages — regenerated by build+publish, not hand-edited |

## Operational model

- **Edit** content/design in `app/src/**` (copy lives in `app/src/data/`).
- **Build** with `cd app && npm run build` (tsc → vite → Playwright prerender). Requires `npx playwright install chromium` once per machine.
- **Publish** with `npm run publish:site` (writes the served files at the repo root).
- **Deploy** is a `git push` of `main` — GitHub Pages serves the repo root. Pushing = going live.
